# 🧠 AI Study Planner — StudyPilot

> Plan smarter. Study better.

StudyPilot is a modern, responsive AI-style study planning web application designed to help students organize their study time, prioritize subjects, and build a structured weekly study schedule.

The application combines a clean dashboard interface with smart JavaScript-based planning logic to create a practical study experience without requiring external libraries or a backend.

---

## ✨ Features

- 📚 Add multiple subjects
- 🎯 Set subject priority
- 🧠 Set subject difficulty
- ⏰ Set daily study hours
- 📅 Set an upcoming exam date
- ✦ Generate a personalized 7-day study plan
- 📊 Track study progress automatically
- ✅ Mark study sessions as completed
- ⏱️ Built-in 25-minute focus timer
- 🎯 Multiple study modes
- 🌙 Dark / Light theme
- 📱 Fully responsive design
- ⚡ Fast browser-based experience
- 🚫 No external libraries required
- 🔌 No backend required

---

## 🎯 Study Modes

### ⚖️ Balanced

Creates an evenly distributed study schedule across your subjects.

### 🎓 Exam Focus

Gives additional priority to subjects marked as high priority.

### 🧠 Weak Subjects

Provides additional weight to difficult subjects so students can spend more time improving challenging topics.

---

## 🧠 Smart Planning Logic

StudyPilot uses a JavaScript-based smart planning algorithm.

The planner considers:

- Subject priority
- Subject difficulty
- Daily available study hours
- Selected focus mode
- Weekly study distribution

Based on these inputs, the application generates a structured 7-day study schedule.

> **Note:** The current version is an AI-style smart planner and does not connect to an external AI API.

---

## 📊 Progress Tracking

Students can mark individual study sessions as completed.

The application automatically calculates:

- Completed tasks
- Total tasks
- Overall completion percentage
- Visual progress bar

This allows students to see their study progress directly from the dashboard.

---

## ⏱️ Focus Timer

StudyPilot includes a built-in 25-minute focus timer inspired by the Pomodoro technique.

Students can:

- Start the timer
- Pause the timer
- Reset the timer
- Complete focused study sessions
